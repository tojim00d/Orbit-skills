# Совместимость — модели и агенты

Orbit сделан под **Claude Code**, где это нативный плагин: команды, субагенты и
скиллы загружаются сами. Сами скиллы — стандартные папки `SKILL.md`, поэтому пак
работает и с другими агентами и моделями.

| Агент / модель | Как использовать Orbit | Команды `/orbit:…` |
|---|---|---|
| **Claude Code** (модели Claude) | `claude plugin marketplace add tojim00d/Orbit-skills` → `claude plugin install orbit@orbit` | ✅ нативно |
| **Claude Code + GLM / Z.ai** (Anthropic-совместимый endpoint) | Та же установка; укажи endpoint GLM | ✅ нативно |
| **Claude Code + Qwen / DeepSeek** (Anthropic-совместимый endpoint или прокси) | Та же установка; настрой модель | ✅ нативно |
| **OpenAI Codex** | Прочитай `AGENTS.md`; скиллы — обычные файлы, скопируй через `./install.sh --skills-dir <dir>` или ссылайся на пути | ❌ обычными словами |
| **Qwen Code** | Как Codex: `AGENTS.md` + `./install.sh --skills-dir <dir>` | ❌ |
| **Агенты на DeepSeek** | Прочитай `AGENTS.md` и нужный `SKILL.md`; или используй DeepSeek как бэкенд Claude Code | ❌ |
| **Cursor / другие IDE-агенты** | Положи `AGENTS.md` и скиллы в проект или скопируй скиллы в папку правил/скиллов агента | ❌ |
| **Любой загрузчик формата Agent Skills** | Укажи на `plugins/orbit/skills/` (или на результат `--skills-dir`) | зависит от загрузчика |

## Что переносится, а что нет

**Переносится (работает везде):**
- 89 скиллов `SKILL.md` и их инструкции;
- контракт артефактов `.orbit/` (`ARTIFACTS.md`);
- каталог, кредиты и эта документация.

**Только Claude Code:**
- слэш-команды и маркетплейс плагинов;
- именованные субагенты (`orbit-cartographer`, `orbit-reverse-analyst`);
- хуки и подстановка `${CLAUDE_PLUGIN_ROOT}` (в скиллах указано, где это заменить).

## Модели

Инструкции скиллов не зависят от модели и написаны простым английским. Пак
протестирован на Claude; GLM, Qwen, DeepSeek и другие сильные instruct-модели
следуют тем же скиллам, если загрузить файлы в контекст. Слабым моделям лучше
давать по одному скиллу, а не маршрут из 3–7 шагов сразу.

## Установка для обычного агента

```bash
git clone https://github.com/tojim00d/Orbit-skills.git orbit
cd orbit
./install.sh --skills-dir ~/.agents/skills   # или папка скиллов твоего агента
```

Затем прочитай `AGENTS.md` в сессии агента и опиши задачу словами. Для артефактов
добавь `.orbit/` в проект.
