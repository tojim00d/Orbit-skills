Orbit — Claude Code skill pack for the full software lifecycle

89 agent skills in one end-to-end pipeline: clarify the task, understand the codebase, write the spec on OpenSpec, build test-first, review code and security, ship to Kubernetes, and keep a living project map. Native Claude Code plugin; the skills are plain SKILL.md folders, so Codex, Qwen Code, DeepSeek and other agents can use them too. Open source, MIT.

Every skill has a step number, an input, an output and a next step. All skills read and write one artifact folder, .orbit/, so work survives new sessions and hand-overs. /orbit:orbit <task> proposes a 3–7 step route and walks it.

What Orbit can do

Understand any codebase

Knowledge graph with file:line evidence, codebase survey, impact analysis, onboarding guide.

Reverse engineering

Docker images, JAR, Helm charts, npm/pip/NuGet, binaries, web apps; OpenAPI from traffic; business rules from legacy.

Spec-driven development

Requirements, design options, specs on OpenSpec, plans of small verifiable steps.

Build and prove

Test-first, subagent delegation, root-cause debugging, code and security review, no "done" without evidence.

DevOps and operations

Kubernetes, Helm, GitOps, CI triage, observability review, runbooks, incident response.

Maps and diagrams

Interactive one-file project maps, static SVG/PNG diagrams, stack diagrams with logos.

Install

claude plugin marketplace add tojim00d/Orbit-skills
claude plugin install orbit@orbit
# restart Claude Code, then:
/orbit:orbit build a feature that exports reports to CSV

From a local clone: ./install.sh. For another agent: ./install.sh --skills-dir <dir> and read AGENTS.md.

FAQ

What is Orbit?Orbit is a free, MIT-licensed skill pack for Claude Code with 89 agent skills organized as one pipeline: Understand, Build, Operate, with shared artifacts in the .orbit/ folder.

How do I install Orbit in Claude Code?Run claude plugin marketplace add tojim00d/Orbit-skills, then claude plugin install orbit@orbit, restart Claude Code and type /orbit:orbit. From a local clone, run ./install.sh.

How is Orbit different from other Claude Code skill packs?Orbit is a sequenced pipeline rather than a collection: every skill has a step number, input, output and next step, and all skills share one artifact folder. Methods from 18 community packs and the ASD-STE100 standard were rewritten and improved, with references in every skill.

Does Orbit work with Codex, Qwen Code, GLM, DeepSeek or other agents?Orbit is native to Claude Code, and its 89 skills are plain SKILL.md folders. Codex, Qwen Code, Cursor and other agents read them via AGENTS.md or ./install.sh --skills-dir; GLM, Qwen and DeepSeek work through a Claude Code-compatible endpoint. Slash commands and subagents are Claude Code-only.

Can Orbit do reverse engineering?Yes, for your own or authorized targets: Docker/OCI images, JAR/WAR, Helm charts, npm/pip/NuGet packages, binaries, web apps, OpenAPI recovery from traffic and business rules from legacy code.

Is Orbit free?Yes. MIT licence for Orbit's own work; borrowed helper tools keep their original licences, listed in CREDITS.md.
