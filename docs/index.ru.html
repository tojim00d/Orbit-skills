Orbit — пак скиллов для Claude Code на весь цикл разработки

89 агентных скиллов в одном конвейере: уточнить задачу, разобраться в кодовой базе, написать спеку на OpenSpec, реализовать через тесты, проверить код и безопасность, выкатить в Kubernetes и держать живую карту проекта. Нативный плагин Claude Code; скиллы — обычные папки SKILL.md, поэтому подходят и Codex, Qwen Code, DeepSeek и другим агентам. Открытый код, MIT.

У каждого скилла есть номер шага, вход, выход и следующий шаг. Все скиллы читают и пишут в одну папку артефактов .orbit/, поэтому работа переживает новые сессии и передачу. /orbit:orbit <задача> предлагает маршрут из 3–7 шагов и ведёт по нему.

Что умеет Orbit

Разобраться в любой кодовой базе

Граф знаний с доказательствами file:line, обзор кодовой базы, анализ влияния, гид онбординга.

Реверс-инжиниринг

Образы Docker, JAR, Helm-чарты, npm/pip/NuGet, бинарники, веб-приложения; OpenAPI из трафика; бизнес-правила из легаси.

Разработка через спеку

Требования, варианты дизайна, спеки на OpenSpec, планы из маленьких проверяемых шагов.

Реализация и доказательство

Сначала тесты, делегирование субагентам, поиск корневой причины, ревью кода и безопасности, «готово» только с доказательством.

DevOps и эксплуатация

Kubernetes, Helm, GitOps, разбор CI, ревью наблюдаемости, runbook, инциденты.

Карты и диаграммы

Интерактивные карты проекта одним файлом, статичные SVG/PNG-диаграммы, схемы стека с логотипами.

Установка

claude plugin marketplace add tojim00d/Orbit-skills
claude plugin install orbit@orbit
# перезапусти Claude Code, затем:
/orbit:orbit сделай фичу, которая экспортирует отчёты в CSV

Из локальной копии: ./install.sh. Для другого агента: ./install.sh --skills-dir <папка> и прочитай AGENTS.md.

Частые вопросы

Что такое Orbit?Orbit — бесплатный пак скиллов под лицензией MIT для Claude Code: 89 агентных скиллов, выстроенных в один конвейер «Разобраться → Разработать → Сопровождать», с общими артефактами в папке .orbit/.

Как установить Orbit в Claude Code?Выполни claude plugin marketplace add tojim00d/Orbit-skills, затем claude plugin install orbit@orbit, перезапусти Claude Code и набери /orbit:orbit. Из локальной копии — ./install.sh.

Чем Orbit отличается от других паков скиллов?Это не набор отдельных скиллов, а конвейер: у каждого шага есть номер, вход, выход и следующий шаг, все пишут в одну папку артефактов. Методы 18 паков сообщества и стандарта ASD-STE100 переписаны и доработаны, источники указаны в каждом скилле.

Работает ли Orbit с Codex, Qwen Code, GLM, DeepSeek и другими агентами?Orbit нативен для Claude Code, а его 89 скиллов — обычные папки SKILL.md. Codex, Qwen Code, Cursor и другие агенты читают их через AGENTS.md или ./install.sh --skills-dir; GLM, Qwen и DeepSeek работают через Claude Code-совместимый endpoint. Слэш-команды и субагенты есть только в Claude Code.

Умеет ли Orbit реверс-инжиниринг?Да, для своих или разрешённых целей: образы Docker/OCI, JAR/WAR, Helm-чарты, пакеты npm/pip/NuGet, бинарники, веб-приложения, восстановление OpenAPI из трафика и бизнес-правила из легаси.

Orbit бесплатный?Да. Orbit под MIT; заимствованные вспомогательные инструменты сохраняют исходные лицензии — они перечислены в CREDITS.md.
