# Security Policy

## Reporting a vulnerability
Please use GitHub's **private vulnerability reporting** (Security → Report a vulnerability). Do not open public issues for security problems.

## Scope
- Helper scripts in `plugins/orbit/skills/*/tools/` and `scripts/`.
- The git-guard hook in `setup-repo`.
- Skill instructions that could lead an agent to unsafe actions.

Orbit contains no offensive-security content. Reverse-engineering skills are scoped to own or authorized targets; bypassing DRM, licence checks or authentication is out of scope.
